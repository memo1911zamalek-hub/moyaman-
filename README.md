# مشوار مصر — لعبة قيادة ويب

لعبة قيادة ثلاثية الأبعاد بسيطة تعمل على الكمبيوتر والهاتف باستخدام HTML وCSS وJavaScript وThree.js.

## التشغيل
- افتح `index.html` عبر خادم محلي (مثل VS Code Live Server)، أو ارفع الملفات الثلاثة إلى مستودع GitHub وفعل GitHub Pages.
- تحتاج اللعبة اتصال إنترنت لتحميل Three.js من jsDelivr وخط Cairo من Google Fonts.

## التحكم
- الكمبيوتر: الأسهم أو A / D.
- الهاتف: اسحب يمين/شمال أو استخدم زري التحكم أسفل الشاشة.
- اجمع العملات الذهبية (+10 جنيه)، وابتعد عن السيارات والتكاتك والنقل.

## المتجر والتعديلات
- العملات تُجمع أثناء القيادة، ويمكن شراء سيارات وفتح كورنيش الإسكندرية مقابل 300 جنيه.
- من الجراج غيّر لون السيارة ودرجة تضليل الزجاج.
- المؤثرات الحالية مولّدة برمجياً. لا تتضمن اللعبة تسجيلات مهرجانات محمية بحقوق النشر. لإضافة موسيقى، ضع ملفات صوت تملك حقوق استخدامها في مجلد `assets` ثم اربطها في `game.js`.

## ملاحظة
هذه نسخة أولية قابلة للتطوير وليست محاكاة قيادة واقعية. اللوحات المصرية هنا تصميم بصري مستوحى من اللوحات المصرية وليست لوحات رسمية دقيقة.
