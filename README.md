# Egypt Drive 3D 🇪🇬

لعبة قيادة ثلاثية الأبعاد بطابع مصري، تعمل في المتصفح على الكمبيوتر والموبايل.

## التشغيل
- افتح `index.html` عبر خادم محلي (مثل VS Code Live Server)، أو ارفع الملفات إلى GitHub Pages.
- اللعبة تستخدم Three.js من CDN، لذلك يلزم اتصال بالإنترنت لتحميل المكتبة والخط.
- لا تحتاج إلى npm أو build step.

## الرفع على GitHub Pages
1. أنشئ Repository جديدًا.
2. ارفع `index.html` و`style.css` و`game.js`.
3. من Settings → Pages اختر Deploy from a branch ثم `main` و`/root`.
4. افتح الرابط الذي ينشئه GitHub Pages.

## التحكم
- الكمبيوتر: A / D أو الأسهم للتحرك، Space للفرامل.
- الهاتف: أزرار اللمس أسفل الشاشة.

## ملاحظات
- الإيقاع الصوتي مولّد برمجيًا داخل اللعبة، وليس ملف مهرجان تجاري.
- العملات افتراضية داخل اللعبة ولا تمثل أموالًا حقيقية.
- هذا إصدار أولي قابل للتوسيع. متجر السيارات والطرق والجراج يعملون كنموذج أولي؛ حفظ المشتريات بين الجلسات، وتغيير خريطة الكورنيش فعليًا، وموديلات سيارات عالية التفاصيل تحتاج مرحلة تطوير إضافية.
